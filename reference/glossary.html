Systems glossary

One vocabulary across every layer.

Language and representation

TermMeaning in this course
ObjectStorage with a type and lifetime under the C model; not necessarily an object-oriented instance.
ValueAn interpretation used by an expression, distinct from raw representation bytes.
ByteC's addressable storage unit; eight bits on the course targets, at least eight by the language contract.
RepresentationThe bits/bytes used to encode a value under a defined format.
EndiannessOrdering of multi-byte value bytes at increasing addresses.
AlignmentA requirement on addresses suitable for objects of a type.
PaddingLayout bytes/bits not part of a named member's value representation.
LifetimeThe interval during which an object exists and may be used according to its contract.
OwnershipThe protocol assigning responsibility for resource use, transfer, and release.
BorrowPermission to use a resource without acquiring its release responsibility.
Dangling pointerA pointer whose former target no longer has a usable lifetime.
Undefined behaviorBehavior for which the language imposes no requirements after a violated condition.
Implementation-definedBehavior the implementation chooses and documents where the standard permits alternatives.
Integer promotionConversion of small integer types before many arithmetic operations.
Modular arithmeticArithmetic reduced modulo a fixed range, as for unsigned integer types.
SignificandThe significant digits of a floating-point value.
ULPA unit in the last place for a specified value/format context; spacing is magnitude-dependent.
SubnormalA floating-point encoding supporting gradual underflow with reduced precision near zero.

Translation and execution

TermMeaning in this course
Translation unitSource after preprocessing, considered as a compilation input.
DeclarationIntroduces a name/type contract; need not provide storage or a function body.
DefinitionSupplies a function body or an object's defining storage declaration under language rules.
Object fileRelocatable machine code/data and metadata; distinct from a C object.
SymbolA named entity in link/debug metadata, such as a function definition or reference.
LinkageSource-level rules about whether declarations denote the same entity across scopes/units.
RelocationMetadata-directed adjustment of a reference after placement or runtime binding.
SectionLink-oriented object/executable subdivision such as code, data, or symbol metadata.
SegmentLoader-oriented region described by program headers in ELF.
ABIBinary interface agreement, including calls, layout, and object conventions.
ISAInstruction-set architecture: programmer-visible machine operations and state.
MicroarchitectureA particular implementation of an ISA.
RegisterNamed architectural state; hardware may rename it internally.
Stack frameState associated with an invocation; optimized execution may not use a conventional frame.
Caller-savedA register whose needed value the caller must preserve across a call.
Callee-savedA register whose incoming value the callee must restore if it changes it.
LatencyTime for one operation/result under a specified model.
ThroughputCompleted useful work per unit time under a specified workload.
DependencyA relation requiring an operation's value or ordering before another operation can proceed.
SIMDOne instruction operating on multiple data lanes.

Memory hierarchy

TermMeaning in this course
Cache lineUnit of cached data transfer/storage and often coherence tracking.
SetGroup of cache locations to which a block can map under the model.
AssociativityNumber of line slots per cache set.
TagBlock-identity information distinguishing candidates mapping to one set.
LocalityReuse in nearby addresses (spatial) or time (temporal).
Conflict missA miss due to mapping constraints rather than simply total capacity.
CoherenceCoordination of cached copies under the architecture's per-location rules.
False sharingContention caused by independent logical objects sharing a coherence line.
Virtual addressAn address interpreted within an address-space context.
Page / frameFixed-size virtual unit / corresponding physical-memory unit in the paging model.
Page tableMapping and permission metadata used for address translation.
TLBCache of address translations, distinct from a cache of application data.
Page faultException requiring OS handling of a translation/protection condition; may be recoverable.
Copy-on-writeSharing until a write requires private storage while preserving separate semantics.
RSSResident-set accounting; not identical to requested live allocation bytes.
Internal fragmentationUnused space inside an allocated block.
External fragmentationFree space split so a needed contiguous request cannot be satisfied.
ArenaStorage region with grouped allocation/lifetime, often reset as a unit.

OS, I/O, networking, concurrency

TermMeaning in this course
ProcessExecution and resource context with an address space and OS-managed identity.
ThreadExecution context sharing process resources with other threads under platform rules.
System callDeliberate request crossing into an OS service interface.
InterruptAsynchronous hardware event relative to the interrupted instruction stream in our model.
SignalOS process/thread notification interface, distinct from the CPU handler itself.
DescriptorProcess-local integer handle referring to an open resource description.
Open-file descriptionShared kernel state behind descriptors, including offset where applicable.
EOFAn interface result indicating stream ending under its object-specific semantics.
Short transferA positive count smaller than requested; not automatically an error.
DurabilityPersistence guarantee under a specified failure/storage model.
FramingRules partitioning a byte stream into application records.
ReadinessNotification that attempting I/O may make progress.
BackpressureLimiting intake or production when downstream capacity is insufficient.
Data raceConflicting non-atomic accesses without required ordering under the language model.
MutexPrimitive coordinating mutual exclusion and visibility under its contract.
PredicateState condition checked under synchronization before proceeding or waiting.
Condition variableWait/notification mechanism paired with a protected predicate and mutex.
Happens-beforeLanguage-model ordering relation used to establish valid inter-thread communication.
Release / acquireMatching atomic ordering operations that can establish synchronization.
DeadlockParticipants cannot progress because of a circular or equivalent unsatisfiable wait.
StarvationA participant fails to obtain needed progress despite others progressing.
LivelockActivity continues without useful completion.

Precision rule

When two layers use the same word, name the layer. A C object is not an object file; an atomic rename is not an atomic C increment; a cache miss is not a page fault. See the sources directory for primary definitions and platform scope.
