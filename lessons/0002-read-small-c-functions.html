Start with a complete function

C gives each expression a type. A type constrains meaningful operations and helps determine the representation used later. Read this function as a state transition, not as punctuation:

c
int sum_positive(const int *values, size_t count) {
    int total = 0;
    for (size_t i = 0; i < count; ++i) {
        if (values[i] > 0) {
            total += values[i];
        }
    }
    return total;
}

The calling code must include <stddef.h> for size_t. int is a signed integer type; size_t is an unsigned type used for object sizes and array counts. Do not assume they have the same range. const int *values lets the function read integers through this pointer, without assigning to those integers through it. We will unpack pointers next.

The function has a contract: values must provide access to at least count live integers when count is nonzero, and the mathematical sum must fit in int. A type declaration alone does not encode that contract. The language's type, expression, and statement rules are specified separately; consult §§6.2, 6.5, and 6.8 when a question becomes precise. Execute it on paper

Initialization happens once. The condition is checked before each body. The increment happens after the body. total += values[i] means add to the current total. == compares; = assigns. A condition treats zero as false and a nonzero value as true.

Make a runnable caller by adding <stdio.h>, defining this function before main, and calling it with an array and its element count. Print the result with %d. Pass count = 0: the loop performs no array access and returns zero. Boundary cases tell you more about an algorithm than a second ordinary input.

Functions pass values

An argument initializes a parameter. Changing a local integer parameter does not change the caller's separate integer. Passing a pointer also passes a value: an address-like value that can designate an object. The receiving function may change that designated object if its contract permits. That is why “C passes by reference” is a misleading shortcut.

A declaration announces a name and type; a definition supplies the function body or an object's storage. Headers typically publish declarations. Put one function definition in a .c file and include a header declaring it from its callers. This distinction will become essential at linking time.

A loop's real preconditions

For arbitrary inputs this function is not a safe general-purpose summation API. If the total exceeds INT_MAX, signed overflow violates the language contract. We have stated the precondition rather than silently assuming machine wraparound. Later we will implement checked arithmetic.

Try changing count to int and comparing it to a size_t index. Enable -Wconversion and inspect diagnostics. A warning can expose a dangerous conversion even when your three-element demonstration looks fine. Do not remove a warning by casting until you can explain the mathematical range. Retrieve before looking

Trace {0, -5, 9, 2} with count = 2. How many reads occur, and what value returns? Then describe the difference between a parameter and the caller's variable.

Worked feedback

There are two reads, of 0 and -5; neither is positive, so the result is zero. The remaining elements are outside this call's requested range. A parameter is a separate object initialized from an argument's value. Predicting eleven here means you followed the physical array length instead of the explicit contract.

Transfer

Change the task to “return the number of positive values.” Write a new invariant: after iteration i, what does the accumulator mean? An invariant explains a loop for all permitted inputs, including the empty one.

Retrieval check

A function receives int n by value and assigns n = 0. What happens to the caller's separate integer?
