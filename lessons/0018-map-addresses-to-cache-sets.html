Map addresses to cache sets

Derive hits and misses from an explicit cache model.

Builds on Lesson 17: Measure a falsifiable claim. Follow the course order on a first pass.

A cache stores blocks

Define a teaching cache with S sets, E lines per set, and B bytes per line. Data capacity is S*E*B, excluding tags and metadata. A byte address selects a block number floor(address/B), a set block mod S, and a tag floor(block/S). The byte offset is address mod B.

For powers of two, these calculations correspond to splitting address bits. With B = 16 and S = 8, four low bits are offset, the next three select the set, and the remaining bits form the tag. Do not confuse byte address with block number.

Work one trace exactly

Use a direct-mapped cache (E = 1) with four sets and eight-byte lines. Begin empty. Access byte addresses 0, 1, 32, 0, 8:

AddressBlockSetTagResult
0000miss; fill
1000hit
32401miss; evict block 0
0000miss; evict block 4
8110miss; fill

One hit in five accesses gives a 20% hit rate. The cache has unused capacity elsewhere, yet addresses 0 and 32 repeatedly displace each other. That is a conflict, not proof that total data capacity was exhausted.

Associativity changes the constraint

With two lines per set, both blocks can coexist in set zero. Replacement policy becomes relevant once a third competing block arrives. The workbench uses least recently used replacement, starts empty, and counts individual read addresses. It does not model stores, prefetching, multiple cache levels, coherence, or exact processor timing.

These omissions are deliberate. A deterministic model teaches mapping; it does not predict your laptop's runtime from an arbitrary trace. Real processor cache indexing can include additional mechanisms, and some levels use virtual/physical address combinations. Consult target documentation before transferring the simple bit split literally. Intel — architecture and optimization manuals

Miss rate is only one term

A simple average-memory-access-time model is hit_time + miss_rate*miss_penalty. If hit time is one model unit, miss rate 0.1, and additional miss penalty 40, average time is five units. The penalty is additional time, so do not count the initial lookup twice.

Real execution can overlap misses, prefetch data, or stall on dependencies. Two traces with the same miss rate can have different runtime because their accesses expose different parallelism. Drepper's memory investigation provides a practitioner's account of the hierarchy; its historical timings are not current hardware constants. Ulrich Drepper — What Every Programmer Should Know About Memory

Retrieve before looking

Use four sets, eight-byte lines, one way, and an empty cache. Predict 0, 8, 0, 32, 0 without running the simulator. Then change only associativity to two.

Worked feedback

Direct-mapped outcomes are miss, miss, hit, miss, miss: one hit. Two-way outcomes are miss, miss, hit, miss, hit: two hits. Addresses 0 and 32 share a set; address 8 uses another. If your answer changes the set calculation when adding ways, revisit which parameter controls set count.

Transfer

Generate two equal-length traces with the same number of unique blocks but different miss rates. Explain why “working set fits in total capacity” is necessary in some cases but insufficient for this cache mapping.
